# คู่มือเทียบราคาค่าจ้างที่ปรึกษา - Design Specification

## เป้าหมาย

สร้างเว็บอ่านอย่างเดียวสำหรับค้นหาและเทียบข้อมูลในเอกสาร ว16 ให้ผู้ใช้เลือกกลุ่มวิชาชีพ วุฒิการศึกษา และช่วงประสบการณ์ แล้วเห็นอัตราค่าจ้างพื้นฐานและ Markup Factor ที่เกี่ยวข้องในหน้าเดียว โดยไม่ต้องเลื่อนค้นหาใน PDF หลายหน้า

## ขอบเขต MVP

- ใช้ Next.js App Router และ TypeScript
- ใช้ Supabase เป็นแหล่งข้อมูลหลักแบบอ่านอย่างเดียว
- มีหน้าเดียวที่ประกอบด้วยแถบค้นหา/Filter ด้านบนและแท็บกลุ่มวิชาชีพด้านล่าง
- แถบค้นหามีช่องค้นหาคำสำคัญ และตัวกรองกลุ่มวิชาชีพ ระดับปริญญา และประสบการณ์
- แท็บแสดงเฉพาะกลุ่มวิชาชีพ และตารางของกลุ่มที่เลือกเมื่อยังไม่มีเงื่อนไขค้นหา
- แสดงแถวที่ตรงเงื่อนไขจากตาราง ว16 พร้อมราคาตามระดับปริญญา
- แสดง Markup Factor ในส่วนผลลัพธ์ที่สัมพันธ์กับเงื่อนไขการค้นหา
- มีสถานะกำลังโหลด ไม่พบข้อมูล และเกิดข้อผิดพลาด
- รองรับหน้าจอ desktop และ mobile
- ไม่มีการเพิ่ม แก้ไข ลบ หรืออัปโหลดเอกสารจากเว็บ

## แนวคิดประสบการณ์ใช้งาน

หน้าบนสุดมีชื่อระบบและคำอธิบายสั้น ๆ ตามด้วยแถบค้นหา/Filter ใน div แยกแบบ sticky และแท็บชื่อกลุ่มวิชาชีพ

เมื่อยังไม่มีคำค้น กลุ่ม หรือช่วงประสบการณ์ที่เลือก จะแสดงตารางทั้งหมดของแท็บที่เลือก เมื่อเริ่มค้นหาหรือกรอง ระบบจะแสดงผลลัพธ์จากทุกกลุ่มเพื่อให้เปรียบเทียบได้ง่าย

ผลลัพธ์ใช้ตารางที่อ่านง่ายบน desktop และเปลี่ยนเป็นรายการการ์ดบน mobile แต่ละรายการแสดงกลุ่มวิชาชีพ ประสบการณ์ วุฒิ และอัตราค่าจ้างอย่างชัดเจน ส่วน Markup Factor แสดงเป็นแผงสรุปแยก เพื่อไม่ปะปนกับตัวเลขอัตราค่าจ้างพื้นฐาน

รูปแบบสีใช้หลัก 60/30/10:

- 60%: พื้นหลังขาวนวลและพื้นผิวตารางสีอ่อน
- 30%: น้ำเงินเขียวเข้มสำหรับหัวข้อ แถบนำทาง และข้อความสำคัญ
- 10%: ส้มอมแดงเป็นสีตัดกันสำหรับปุ่ม จุดเน้น และสถานะที่เลือก

ต้องรักษาความเปรียบต่างของข้อความและไม่ใช้สีเป็นวิธีสื่อความหมายเพียงอย่างเดียว

## โมเดลข้อมูล Supabase

ใช้ตารางที่แยกหน้าที่ชัดเจน:

### `w16_rate_rows`

- `id` uuid primary key
- `professional_group` text not null
- `experience_years` numeric not null
- `experience_label` text not null
- `bachelor_rate` numeric
- `master_rate` numeric
- `doctorate_rate` numeric
- `source_page` integer
- `source_table` text
- `notes` text
- `created_at` timestamptz

### `w16_markup_factors`

- `id` uuid primary key
- `factor_type` text not null
- `factor_label` text not null
- `factor_value` numeric not null
- `description` text
- `source_page` integer
- `sort_order` integer
- `created_at` timestamptz

### `w16_rate_markup_map`

- `rate_row_id` uuid references `w16_rate_rows(id)`
- `markup_factor_id` uuid references `w16_markup_factors(id)`
- primary key (`rate_row_id`, `markup_factor_id`)

ทุกตารางเปิดเฉพาะการอ่านสำหรับบทบาทที่หน้าเว็บใช้ และข้อมูลที่นำเข้าแล้วต้องเก็บเลขหน้า/ชื่อตารางจาก PDF เพื่อย้อนตรวจสอบได้

## การจับคู่และการแสดงผล

การค้นหาทำงานจากข้อมูลที่โหลดมาจาก Supabase โดยกรอง `professional_group`, `experience_years`/`experience_label`, ระดับปริญญา และคำค้นในกลุ่มวิชาชีพหรือหมายเหตุ เมื่อเลือกวุฒิ ระบบจะเน้นคอลัมน์ราคาที่ตรงกับวุฒินั้น แต่ยังแสดงราคาของวุฒิอื่นในแถวเดียวกันเพื่อให้เปรียบเทียบได้

ในโหมดดูตามกลุ่มวิชาชีพ ระบบจะจัดกลุ่มแถวด้วย `professional_group` และเรียงตาม `experience_years` จากน้อยไปมาก แท็บแรกเป็นกลุ่มแรกตามลำดับข้อมูล และ URL จะเก็บกลุ่มที่เลือกไว้เพื่อให้เปิดหรือแชร์มุมมองเดิมได้

Markup Factor จะถูกกรองจากความสัมพันธ์ใน `w16_rate_markup_map` ถ้าไม่มี mapping เฉพาะ ให้แสดงรายการ factor ที่ตรงกับหมวดค้นหาและระบุว่าเป็นข้อมูลอ้างอิงทั่วไป ไม่แสดงค่าที่อนุมานขึ้นเอง

## สถานะข้อมูล

- กำลังโหลด: แสดงโครงร่างของแถบตัวกรองและผลลัพธ์
- พบข้อมูล: แสดงจำนวนผลลัพธ์ ตาราง และแผง Markup Factor
- ไม่พบข้อมูล: แสดงข้อความและปุ่มล้างตัวกรอง
- Supabase ผิดพลาด: แสดงข้อความที่เข้าใจง่ายและปุ่มลองใหม่
- ไม่มีค่า environment: ใช้ข้อความแจ้งการตั้งค่า ไม่ฝัง secret ใน source code

## การตรวจสอบ

- ตรวจ TypeScript และ production build
- ตรวจว่าการกรองแต่ละตัวลดผลลัพธ์ได้ถูกต้อง
- ตรวจว่าสลับระหว่างโหมดค้นหาและโหมดดูตามกลุ่มวิชาชีพได้ และแท็บแสดงเฉพาะตารางของกลุ่มที่เลือก
- ตรวจว่าการเลือกปริญญาเน้นราคาคอลัมน์ที่ถูกต้อง
- ตรวจว่าเมื่อไม่พบ mapping ของ Markup Factor จะไม่แสดง factor แบบเดาสุ่ม
- ตรวจการแสดงผลบน viewport desktop และ mobile ด้วยการเปิด preview ใน browser

## นอกขอบเขต

- ระบบอ่าน OCR หรือแยกข้อมูลจากเอกสารที่ผู้ใช้อัปโหลด
- ระบบจัดการผู้ใช้และสิทธิ์แบบเต็มรูปแบบ
- การคำนวณราคาสุทธิจากข้อมูลที่กรอกใหม่
- การแก้ไขข้อมูลใน Supabase ผ่านหน้าเว็บ

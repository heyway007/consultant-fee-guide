# คู่มือเทียบราคาค่าจ้างที่ปรึกษา ว16

เว็บ Next.js แบบอ่านอย่างเดียวสำหรับค้นหาและเปิดดูตารางอัตราเงินเดือนพื้นฐานของ 10 กลุ่มวิชาชีพ พร้อม Markup Factor ที่เกี่ยวข้อง

## มุมมองการใช้งาน

- แถบค้นหาและ Filter อยู่ด้านบนของหน้าเสมอ
- แท็บด้านล่างมีตัวเลือก “ทุกกลุ่มวิชาชีพ” และแท็บแยกของแต่ละกลุ่ม โดยเปิดตารางทั้งหมดของมุมมองที่เลือกเมื่อยังไม่มีเงื่อนไขค้นหา
- เมื่อกรอกคำค้นหรือเลือก Filter ระบบจะแสดงผลลัพธ์จากทุกกลุ่ม
- ระดับปริญญาที่เลือกจะถูกเน้นในตาราง แต่ยังคงแสดงราคาอีกสองระดับเพื่อเปรียบเทียบ
- แถวข้อมูลและ Markup Factor เก็บเลขหน้า/ชื่อตารางต้นทางเมื่อมีข้อมูลจริง

## เริ่มต้นใช้งาน

```powershell
npm install
npm run dev
```

เปิด `http://localhost:3000`

เว็บใช้ข้อมูลจากไฟล์ JSON ในโฟลเดอร์ `data/` โดยตรง ไม่ต้องตั้งค่าฐานข้อมูลหรือ environment variable เพิ่มเติม

## Note: เกณฑ์บุคลากรและ Markup Factor

ระบบจัดบทบาทบุคลากรอัตโนมัติจากวุฒิการศึกษาและประสบการณ์ โดยใช้เกณฑ์ `≥` ดังนี้:

- ปริญญาตรี ประสบการณ์ `≥ 10 ปี` = บุคลากรหลัก
- ปริญญาโท ประสบการณ์ `≥ 5 ปี` = บุคลากรหลัก
- ปริญญาเอก ประสบการณ์ `≥ 2 ปี` = บุคลากรหลัก
- หากไม่ถึงเกณฑ์ = บุคลากรผู้ช่วย

Markup Factor ทั้งหมดเชื่อมโยงจาก 3 เงื่อนไข คือ บทบาทบุคลากร ประเภทหน่วยงาน และจำนวนหลักฐาน:

- บริษัท / มูลนิธิ / สมาคม — บุคลากรหลัก: หลักฐานครบ 3 ข้อ `×2.640`, 2 ข้อ `×2.555`, 1 ข้อ `×2.530`, ไม่มีหลักฐาน `×2.475`
- บริษัท / มูลนิธิ / สมาคม — บุคลากรผู้ช่วย: `×2.255` ไม่ปรับตามจำนวนหลักฐาน
- ภาครัฐ / สถาบันการศึกษาของรัฐ — บุคลากรหลัก `×1.760`, บุคลากรผู้ช่วย `×1.456`
- ที่ปรึกษาอิสระ: `×1.430`

บุคลากรสนับสนุนเป็นทีมงานแยกจาก Markup Factor มีอัตราค่าตอบแทนรายเดือนคงที่ ไม่ใช้วุฒิการศึกษาและประสบการณ์ในการคำนวณ:

- ช่างเทคนิค `31,120 บาท/เดือน`
- เลขานุการ `20,000 บาท/เดือน`
- พนักงานพิมพ์ดีด `18,180 บาท/เดือน`
- พนักงานธุรการ `15,460 บาท/เดือน`

สูตรคำนวณบุคลากรสนับสนุนคือ `เงินเดือนประจำตำแหน่ง × จำนวนเดือน × สัดส่วนการทำงาน (%)` และไม่รวม Markup Factor

## Build บน Cloudflare Workers

โปรเจกต์เตรียม OpenNext และ Wrangler สำหรับ Cloudflare Workers ไว้แล้ว โดยใช้คำสั่ง:

```powershell
npm run build:cloudflare
npm run preview:cloudflare
```

สำหรับ Cloudflare Workers Builds ต้องกำหนดคำสั่งแยกกันดังนี้:

```text
Build command:  npm run build:cloudflare
Deploy command: npm run deploy:cloudflare
```

อย่าใช้ Deploy command ค่าเริ่มต้น `npx wrangler deploy` เพราะ OpenNext ต้องเตรียมและ deploy output ผ่าน `opennextjs-cloudflare` เอง ระบบจะอ่านการตั้งค่าจาก `wrangler.jsonc` และใช้ output ใน `.open-next/` สำหรับ Worker

ถ้าต้องการ build และ deploy จากเครื่องในคำสั่งเดียว ให้ใช้:

```powershell
npm run release:cloudflare
```

บนเดสก์ท็อป/โน้ตบุ๊กที่กว้างกว่า 960px และสูงอย่างน้อย 660px ใช้พื้นที่ทำงานสูงเท่าหน้าจอ (`100dvh`) ให้ตัวกรอง ตาราง ปุ่มเปลี่ยนหน้า และส่วนคำนวณอยู่ในหน้าจอเดียวกัน ลดระยะห่างและจัดช่องคำนวณเป็น 2 × 2 ช่อง หรือแถวเดียว 4 ช่องบนจอกว้างอย่างน้อย 1200px ที่สูงไม่เกิน 850px ฝั่งขวาสลับแท็บที่ปรึกษา/บุคลากรสนับสนุนได้โดยค่าที่กรอกไว้ทั้งสองส่วนยังคงอยู่ รองรับปุ่มลูกศรซ้าย/ขวา Home และ End สำหรับเปลี่ยนแท็บด้วยคีย์บอร์ด หากเลือกแสดงรายการจำนวนมากจะเลื่อนเฉพาะภายในตาราง ส่วนจอเล็กหรือการขยายหน้าจอมากใช้การเลื่อนตามเนื้อหาเพื่อไม่ตัดช่องกรอก

การแสดงผลตารางและส่วนคำนวณบนจอใหญ่แบ่งความกว้างเท่ากัน (6/6) และเรียงเป็นคอลัมน์เดียวบนจอกว้างไม่เกิน 960px ตารางแบ่งหน้าเริ่มต้น 10 รายการ (5 รายการสำหรับโน้ตบุ๊กที่กว้างกว่า 960px และสูงไม่เกิน 850px) เลือกแสดง 5, 10, 20, 50 หรือทั้งหมดได้ โดยใช้กับการ์ดบนมือถือด้วย เมื่อเปลี่ยนตัวกรอง หมวดหมู่ หรือจำนวนรายการต่อหน้า จะกลับไปหน้าแรก จำนวนแถวด้านบนยังแสดงยอดรวมที่ตรงกับตัวกรองทั้งหมด
